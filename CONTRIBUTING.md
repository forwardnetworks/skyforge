# Contributing

This repository is our working setup, shared as is. We are not taking pull requests yet.

What helps most:

- **Open an issue** when a patch series stops applying to its pin in [UPSTREAM.md](UPSTREAM.md), when a blueprint does not compile or boot, or when the install guide is wrong. Say which series or blueprint, the pin, the command you ran and its output.
- **Fixes to the upstream projects themselves** (netlab, KNE, koko, meshnet-cni and the others) belong upstream. Tell us if a patch here is affected.
- **Security problems**: see [SECURITY.md](SECURITY.md). Do not open a public issue.

We read every issue but do not promise a response time.
